# 유튜브 쇼츠 제작 (2026-11-26 시작, 기원님 승인)
- 형식: 세로 1080×1920, 30fps, 25~40초. 목소리 없음(기원님: 개인 목소리 안 넣음) → 큰 자막 + 직접 합성한 배경음(sound.py, 저작권 문제 없음) + 강조 효과음.
- 캐릭터·색은 카드뉴스 v2와 같음(ch/*.svg). 장면 부품: parts.py (cover·chat·tiles·ox·big·compare·ending).
- 만들기: `python3 _ops/shorts/engine.py _ops/shorts/specs/sNN.py` (먼저 `--preview`로 장면 끝 화면 확인) → `_ops/shorts/out/<NAME>/final.mp4` (out/은 저장소에 올리지 않음).
- 세법 내용 원칙은 홈페이지와 같습니다(법제처 현행 조문 확인, 숫자는 python 검산, 예규·판례는 확인된 것만). BASIS에 근거 조문과 기준일을 적으면 마지막 장면에 표시됩니다.
- 시리즈 번호는 카드뉴스와 별도로 셉니다: 증여세 절세 series 4편까지, 양도세 절세 series 2편까지, 상속세 절세 series 1편까지 사용(1주차 7편).
- 게시: 유튜브 연결 도구가 없어 기원님이 유튜브 스튜디오에서 7편을 올리고 하루 1편씩 '예약'합니다. 제목·설명 문구도 함께 만들어 드립니다.
- 하단 약 350px·오른쪽 끝은 유튜브 버튼에 가려지므로 핵심 내용은 위쪽에 둡니다.
